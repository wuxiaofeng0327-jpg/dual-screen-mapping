# 双幕映射

浏览器中的天幕与环幕映射工具。静态文件位于 `dist/`，无需后端或构建。

用户导入的素材由 File API 在用户设备上读取，不上传服务器。发布内容包含程序、影院几何快照、依赖，以及用户授权公开的 `21-9` 测试视频兼容版；不包含其他项目素材、Blender 文件或本地路径。

默认从离地 1.5 米的固定眼位观察，鼠标左右反向默认开启；参数栏位于 3D 窗口右侧。下方提供贝塞尔网格、对称、区域控制、拼接线、吸附及时间轴。清空素材恢复测试网格并保留映射。

首次打开自动载入 `samples/21-9-h264.mp4`（4398×1886、24 fps、H.264 8 位兼容版、30 Mbps 目标码率），保留原测试片的帧时间与 AAC 音频，不自动播放。清空或自行导入可取消默认加载；已保存工程中明确关闭的鼠标反向设置仍会保留。

3D 工具栏右侧的“参数”按钮收起或展开右侧菜单，收起后画面自动扩展；开关状态随工程保存。

## 输出

- PNG：环幕、天幕、双幕拼接、原画幅变形，保留输入宽度（含奇数）。
- 视频：H.264 MP4，默认目标码率 30 Mbps，保留原始帧时间与主音轨。H.264 奇数宽度补齐到偶数。
- Web Worker 按实际输出像素计算一次映射，WebGL 对原始解码帧采样。不会导出 2048 像素的预览纹理。
- 桌面 Chrome / Edge 可通过文件夹输出直接写盘；小文件也可生成下载链接。文件、工程和导出结果不上传。
- 视频解码、H.264 编码及最大尺寸受浏览器与显卡限制。不支持时报告错误，不静默缩小或丢弃音轨。导出时需要保持页面打开。
- 保存的工程兼容本地版 v1–v3；素材需要重新选择。

## 本地运行

安装 Python 3 后，在仓库目录运行：

```console
python -m http.server 8080 --bind 127.0.0.1 --directory dist
```

打开 http://127.0.0.1:8080/。视频导出需要 localhost 或 HTTPS，以及支持 WebCodecs 的桌面 Chrome / Edge。

如果已安装 Node.js，可运行 `npm run check` 检查源码；运行网页不需要安装 npm 依赖。

当前几何为 Blender 导出快照，网站不连接访问者的 Blender。修改模型时需重新导出几何。

## 依赖

Three.js 0.180.0（MIT）与 Mediabunny 1.61.6（MPL-2.0）原版浏览器分发文件位于 `dist/vendor/`，许可随文件分发。无外部 CDN 运行依赖。

## 验证

2026-10-20，在桌面 Edge 中完成：

- 四种 PNG（源 721×517），包括拼接控制线和变形；对照本地 Python 映射，RGB 平均误差均小于 0.04/255。
- 四种 H.264（源 4398×1886，30 Mbps 目标码率），输出分别为 4398×600、4398×1446、4398×1600、4398×1886；6 帧测试片全部保留，AAC 音轨保留。
- 浏览器真实文件系统流式输出、取消及恢复、清空素材、固定眼位与界面布局。
- 请求检查确认无素材上传。

## 循环播放

底部播放栏的“循环”按钮默认开启并高亮。点击关闭后，视频播到结尾停止；图片及未加载素材时按钮禁用。此开关只影响预览播放，不会重复导出视频。

## 部署

将 `dist/` 目录作为网站根目录部署到支持 HTTPS 的静态托管服务即可，无需后端服务、数据库或 API 密钥。保持目录结构，以便加载模型、依赖和默认测试视频。

本仓库包含浏览器版源码与已公开的测试资源，不包含本地 Python 导出服务、Blender 工程或用户导入的私人素材。第三方依赖许可保存在 `dist/vendor/`。
